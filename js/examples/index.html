OpenDither on the web

Two ways to use it: the <open-dither> element, or OpenDither.auto() on regular images. Hover the first image to reveal the original.

Usage

<script src="opendither.js"></script>
<script src="opendither-element.js"></script>

<open-dither src="photo.jpg" algorithm="atkinson" palette="#000,#fff" scale="2"></open-dither>

<img src="photo.jpg" data-dither="bayer-4" data-palette="sepia">
<script>OpenDither.auto()</script>

Open this page through a local web server (for example python -m http.server in the repo root). Browsers block reading pixels from file:// pages and from cross-origin images without CORS headers.
